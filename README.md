# 말로 — 내 PC에서만 도는 한국어 Windows 음성 입력

말한 내용을 **지금 커서가 있는 입력칸에 바로** 넣습니다.
받아쓰기와 문장 정리를 **전부 내 컴퓨터에서** 처리합니다. 계정도, API 키도, 인터넷도 필요 없습니다.

[![다운로드](https://img.shields.io/badge/다운로드-Windows%20x64-087F82?style=for-the-badge)](https://github.com/daniel-kim-9way/malro/releases/latest)

---

## 무엇을 하나

- **단축키 한 번 → 말하기 → 다시 한 번** 이면 정리된 문장이 입력칸에 들어갑니다.
- 입력칸이 없어도 됩니다. 결과는 **항상 클립보드에도** 남습니다.
- 한 번에 **최대 10분**까지 말할 수 있습니다. 쉬는 구간마다 미리 인식해서 말을 마친 뒤 기다리는 시간을 줄입니다.
- **정리 방식**을 고릅니다 — 그대로 받아쓰기 / 문단만 정리 / 말을 자연스럽게 정리.
- **쓰는 곳**에 맞춰 모양이 달라집니다 — AI에게 요청(소제목·번호) / 메모(목록) / 메일(문단).
- **앱별로** 정리 방식·쓰는 곳·받아쓰기 모델·문장 정리 모델을 따로 지정할 수 있습니다.
- 자주 쓰는 **이름·용어**를 등록하면 그 표기로 받아씁니다.
- 말한 원문과 정리 결과를 **이 PC에 함께 보관**합니다. 검색·비교·즐겨찾기·내보내기가 됩니다.
- 이미 쓴 글을 **선택하고 말로 고칠** 수 있습니다.

## 내 컴퓨터에서 처리한다는 뜻

- 음성 인식은 **Whisper**, 문장 정리는 **Ollama**의 로컬 모델이 합니다. 둘 다 내 PC에서 돕니다.
- 말한 내용도, 정리된 글도 **외부로 나가지 않습니다.**
- 그래서 **사용량 제한도, 구독료도 없습니다.**
- 대신 모델을 한 번 내려받아야 하고(첫 실행 화면이 안내합니다), PC 성능과 저장 공간을 씁니다.
- 음성 파일은 **저장하지 않습니다.** 원문·결과는 `%LOCALAPPDATA%\Malro\history.sqlite3`에 남고, 설정에서 끄거나 지울 수 있습니다.

## 설치

1. [Releases](https://github.com/daniel-kim-9way/malro/releases/latest)에서 `Malro-Setup-0.6.6-windows-x64.exe`를 받습니다.
2. 실행하고 안내를 따릅니다. 관리자 권한은 필요 없습니다(내 계정 폴더에 설치됩니다).
3. 첫 실행 화면에서 **PC 사양을 확인하고 맞는 모델을 추천**해 줍니다. 그대로 받으면 됩니다.

> ⚠️ 서명되지 않은 설치 파일이라 Windows SmartScreen이 한 번 경고할 수 있습니다.
> `추가 정보` → `실행`으로 진행하세요. 파일이 맞는지는 아래 체크섬으로 확인할 수 있습니다.

**필요 사양** — Windows 10 (빌드 19045 이상) 또는 Windows 11, 64비트.

**파일 확인** — 각 릴리스의 `SHA256SUMS.txt`와 비교하세요. PowerShell:
```powershell
Get-FileHash .\Malro-Setup-0.6.6-windows-x64.exe -Algorithm SHA256
```
